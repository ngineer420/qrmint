About the Wi‑Fi QR code format

This tool encodes your network details using the standard WIFI: payload that iOS and Android's camera apps recognize automatically — no separate app required. Scanning the code offers to join the network directly; on most phones a single tap connects. The security type matters: pick WPA/WPA2/WPA3 for almost any modern router, WEP only for very old hardware, or "Open" for networks with no password at all.

Is it safe to print a Wi‑Fi QR code?

The code contains your actual password in plain text once decoded, so treat a printed Wi‑Fi QR code the way you'd treat the password itself — fine for a home entryway or a guest-only network, less fine for a shop window facing a public street. For a guest network with no lasting risk, set up a router-level guest SSID and point the code at that instead of your primary network.

Frequently asked questions

Which phones can scan a Wi‑Fi QR code?

Any iPhone running iOS 11+ and any Android phone running Android 10+ can scan and join directly from the built-in camera app. Older phones may need a separate QR scanner app that supports Wi‑Fi payloads.

Does this work for 5GHz networks?

Yes — the QR code just carries the network name and password; it works the same regardless of which band or channel the router uses.

Can I add a cafe or house logo to the middle?

Yes — pick an image under Center logo and it is drawn in the middle of the code, with error correction raised to H so the code still scans. Every render is then decoded again in this tab, so you get a Scan-verified badge before you print it rather than a surprise at the door.

What if my network name or password has special characters?

QR Mint automatically escapes semicolons, commas, colons, quotes and backslashes so the payload stays valid no matter what's in your SSID or password.
