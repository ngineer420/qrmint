How QR Mint works

QR Mint builds every code with a compact QR Code encoder that runs entirely inside your browser — the same Reed–Solomon error correction and masking logic used by professional QR libraries, just with no server round-trip. Type a link, Wi‑Fi network, contact, or note; the preview updates live; hit Mint PNG or Mint SVG to download. Nothing you enter is ever sent anywhere — close the tab and it's gone.

Choosing an error-correction level

QR codes carry their own repair data, so they can still scan even if part of the code is scuffed, glared, or partly covered by a logo. Higher levels (Q, H) survive more damage but need a denser, larger code for the same content — L or M is plenty for a clean screen or sticker; go higher for anything printed small, laminated, or likely to get scratched.

Putting a logo in the middle

Pick an image and QR Mint draws it dead centre, at 10–25% of the code, with an optional knocked-out plate behind it so the logo sits on clean background instead of on top of modules. Adding a logo locks error correction to H: H sets aside about 30% of the code as repair data, and that spare capacity is exactly what a centre logo spends. Your file is read with FileReader and drawn straight onto the canvas — it is never uploaded, and it rides along inside the SVG as a data: URI so the exported file stays self-contained.

Scan verification: the part nobody else does

Every time the preview changes, QR Mint reads the code back with the same decoder that powers the QR code reader, and tells you whether it actually scanned. A green Scan-verified badge means the code decoded to exactly what you typed. A red warning means it did not — and it names the fix, whether that is a smaller logo, more contrast, or a higher error-correction level. Most generators will happily let you style a code into something unreadable, and you find out after the flyers are printed. This one closes that loop before you download.

FAQ

Is this really free, with no sign-up?

Yes. QR Mint doesn't have accounts, limits, or watermarks — mint as many codes as you like.

Do my QR codes expire?

No. Every code QR Mint generates encodes your actual content directly (a "static" QR code) — there's no redirect service in the middle that could go offline or expire.

PNG or SVG — which should I use?

SVG is a vector file that stays crisp at any size — best for print, posters, and anything you might resize later. PNG is a fixed-size image — simplest for slides, docs, and the web.

Can QR Mint read a code as well as make one?

Yes — the QR code reader decodes a code from a photo, a screenshot you paste, or your camera, and shows you what it actually contains before you act on it. Like everything else here, the image and the camera feed are processed in this tab and never uploaded.

I need hundreds of codes. Do I have to make them one at a time?

No. Batch from CSV takes a spreadsheet export, mints one code per row, names each file from a column you choose, and hands the whole set back as a single ZIP.

Can I put my logo in the middle of the QR code?

Yes. Choose an image under Center logo and it is drawn in the middle at the size you pick, with an optional rounded or circular plate behind it. Error correction jumps to H automatically so the code survives the modules the logo covers, and the PNG and SVG downloads look identical. The image never leaves your browser.

How do I know a logo hasn't broken my code?

QR Mint scans its own output. After each change the code is decoded again in the browser; you get a green Scan-verified badge when it reads back correctly, and a red warning naming the exact fix when it doesn't. You never have to trust that a styled code still works — you can see that it does.

Does anything I type get uploaded?

No. Every code is built and rendered locally, in your browser's own memory. QR Mint has no backend that ever sees your links, Wi‑Fi password, or contact details.
